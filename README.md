# GradeUp – Student Growth Platform 

GradeUp is a browser-based student development dashboard built with HTML, CSS and Vanilla JavaScript.

## Why this version?
The project is intentionally not just a CGPA calculator. It treats academic performance as one part of a student's development and tracks:
- Technical skill growth
- Skill evidence / targets
- Weekly learning consistency
- Semester performance
- Career direction
- Placement readiness

## Features
1. Dashboard with CGPA, skill growth, weekly growth and placement readiness.
2. Skill tracker with levels and evidence-oriented targets.
3. Weekly activity tracker with target vs completed work.
4. Academic semester/SGPA tracker.
5. Career-path roadmap for Software Developer, Full Stack Developer, Data Analyst and QA/Test Engineer.
6. Placement-readiness checklist across DSA, technical skills, projects, aptitude, communication and resume/GitHub.
7. LocalStorage persistence.
8. Responsive layout for desktop and mobile.
9. No framework, server or database required.

## Tech stack
HTML5, CSS3, Vanilla JavaScript, LocalStorage.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Important for resume
Only claim features you have actually tested and understand. Be prepared to explain DOM manipulation, event listeners, arrays/objects, calculations, conditional rendering and LocalStorage.
